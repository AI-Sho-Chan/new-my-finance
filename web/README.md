MyFinance (React + Vite)

開発用メモ

- 起動: `npm install` -> `npm run dev`
- ビルド: `npm run build` -> `npm run preview`
- 主要技術: React (TS), Vite, Tailwind CSS, Zustand, lightweight-charts

概要

- ダッシュボード: ウォッチリスト銘柄カードを表示。カードクリックで詳細チャートモーダルを開く。
- ポートフォリオ: 現金(JPY/USD), 株式, 暗号資産の追加/編集/削除/並び替え。総資産/現金/投資の集計と前日比を表示。資産推移チャートを表示。
- 詳細チャート: ローソク足 + 50/200MA + ボリンジャーバンド + 出来高。日足/週足/月足切替。
- データ: 外部APIや鍵は不要。ダミーの市場データ/ヒストリカルを内製で生成。ローカルストレージへ永続化。

既知の制限

- カード内の超小型スパークラインは未実装（必要なら追加可能）。
- 実データAPI連携は未実装（自律データで運用）。


## Q1 監視機能

- `web/server` 側に Yahoo Finance をポーリングする Q1 モニタを追加しました。市場時間中 (日本/米国) に 5 分間隔で実行し、新規 Q1 判定と Q1 落ちを検知します。
- 検知した銘柄はフロントエンドのウォッチリストでシステムタグ `Q1` に自動同期され、分析タブにも専用ビュー (Q1) が追加されます。
- 直近イベントはダッシュボード上部のバナーで通知され、履歴は分析タブの「Q1履歴」カードから確認できます。

### 環境変数

| 変数名 | 必須 | 説明 |
| --- | --- | --- |
| `Q1_ALERT_EMAIL_USER` | ○ | Gmail アカウント (アラート送信元)。アプリパスワード等を利用してください。 |
| `Q1_ALERT_EMAIL_PASS` | ○ | 上記アカウントのアプリパスワード。 |
| `Q1_ALERT_EMAIL_TO`   | ○ (省略時は USER) | アラート送信先メールアドレス。複数指定する場合はカンマ区切り。 |
| `Q1_ALERT_EMAIL_FROM` | 任意 | メールの From 表示。省略時は USER と同じ。 |
| `Q1_MONITOR_INTERVAL_MIN` | 任意 | 通常ポーリング間隔 (分)。既定値 5 。 |
| `Q1_MONITOR_FALLBACK_MIN` | 任意 | 失敗時のバックオフ間隔 (分)。既定値 10 。 |

環境変数は `web/server/index.mjs` を起動するプロセスに渡してください。メール送信を無効化したい場合はユーザー/パス未設定のままでも動作します (バナー通知とタグ同期のみ)。
